# Secondary analysis 002 — phase-specific state and later intrusive memories

8 September 2026. Exploratory specification fixed after reading the published results and data dictionary, before downloading the numerical table. This is not preregistered discovery or an independent replication sample.

Source: deBettencourt et al., AI-guided digital intervention with physiological monitoring reduces intrusive memories after experimental trauma, DOI 10.1038/s41746-025-02145-5. Public numerical data: https://osf.io/anvuk/. Preserve file hashes and metadata. Analyze only the aggregate numerical participant table; no free-text trauma logs are needed.

1. Reproduce the unadjusted intervention–control mean difference in IntrusionsTotal, using all available randomized participants without outcome-based exclusions. Report group sizes, mean, median and a two-sided permutation test with 10,000 random assignments preserving group sizes. This reanalysis concerns the assigned intervention package; both groups received AI guidance, so it does not isolate an AI effect or prove a pupil-guided controller.
2. Screen whether pre-task physiology improves prediction of the later count beyond treatment assignment and pre-film mood. Features: InterventionCondition; the mean of the three pre-film mood ratings; PupilBaseline; PupilRest minus PupilBaseline; PupilMemoryReminderEffect. Treat post-randomization pre-task features as predictors only, not validated treatment-effect modifiers. Missing feature values are imputed with training-set medians within each fold. Include missingness indicators; drop globally entirely missing columns, reporting this.
3. Use the same nested participant-held-out ridge implementation and fixed penalty grid as analysis 001. Compare (a) treatment alone, (b) treatment plus pre-film mood, (c) b plus pre-task pupil features, (d) c plus PupilCognitiveTaskEffect. Models c/d are predictive screens, not estimators of individualized causal effects. Model d measures engagement during treatment and is unavailable for the earlier treatment decision.
4. Fit the published exploratory two-pupil-predictor linear association in the intervention arm, complete cases only: total intrusions against PupilMemoryReminderEffect and PupilCognitiveTaskEffect with an intercept. Report coefficients and sample size; no search for a favorable subset. This is a check of a reported association, not a new finding. Differences from the authors' figures require investigation rather than silent adjustment.

Interpretation: average efficacy does not establish the value of personalization. Opposite phase associations do not identify optimal arousal targets; pupil size can reflect effort, luminance and other factors. A test of state-guided timing requires randomized timing or a suitably designed sequential trial, and independent symptom/function follow-up. Do not pool participants with the unrelated PhysioNet cohort or transfer its units, labels, model weights or effect sizes.
